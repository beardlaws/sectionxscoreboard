# Navigation goal

Every destination should answer the current question and offer the next useful click.

Game -> team, school, athlete, standings, next game, photos.
Team -> game, roster athlete, standings, history, gallery.
Athlete -> team, games, stats, awards, photos.
School -> teams, today's games, results, galleries, history.

The goal is not artificial infinite scroll. It is a dense network of genuinely relevant paths that makes leaving unnecessary.
