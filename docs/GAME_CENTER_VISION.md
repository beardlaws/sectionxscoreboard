# Section X Scoreboard vision

Section X Scoreboard should become the first place people check for what is happening tonight and the place they return to understand what happened years ago.

The flywheel:
Schedules bring people in -> scores create daily habit -> Game Centers add depth -> photos create community -> rosters create athlete identity -> stats create leaders/careers -> history creates permanence.

Build every feature so it strengthens that flywheel instead of becoming an isolated page.
