# Game data completeness

Game Center must remain useful regardless of how much data a school provides.

- Level 1: final/upcoming score and game metadata
- Level 2: period/quarter/inning/set scoring
- Level 3: team stats
- Level 4: athlete box score

UI modules are progressive: advanced sections do not render when their data is absent. A score-only game remains a first-class Game Center page, not an incomplete/error state.
