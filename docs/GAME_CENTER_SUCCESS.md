# Game Center success signals

Near term:
- More score cards clicked into game pages
- Photo submissions tied directly to games
- Repeat visits on game nights
- More approved photos reused across connected pages

Long term:
- Percentage of games with recaps/photos/advanced stats
- Athlete profile visits
- Team/school hub depth and return visits
- Search traffic to historical game/athlete pages
- Trusted school/coach/contributor participation
