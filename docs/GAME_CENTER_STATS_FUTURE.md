# Future stat breadth

The stat-definition model is intentionally open-ended.

Basketball: points, rebounds, assists, steals, blocks, shooting.
Soccer/hockey/lacrosse: goals, assists, saves, shutouts and sport-specific extras.
Football: passing, rushing, receiving, defense, kicking.
Baseball/softball: batting, pitching, fielding.
Volleyball: kills, assists, aces, blocks, digs.
Wrestling: opponent, result, weight, pins, points.
Track/swimming: event, mark/time, place, PR.
Golf: score and place.

The initial seed is intentionally small; adding a new stat should usually be data/configuration, not a schema migration.
