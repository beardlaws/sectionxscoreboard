# Rollout strategy

Ship visible value in small slices:
1. Connected photo submissions.
2. Game-page photo CTA and improved gallery.
3. Period scoring + admin editor.
4. One sport's full box score end-to-end.
5. Expand stat definitions sport by sport.
6. Connected team/school/athlete galleries.
7. Leaders/career totals once verification workflow is proven.

This keeps production useful throughout the build instead of hiding everything behind a giant unfinished rewrite.
