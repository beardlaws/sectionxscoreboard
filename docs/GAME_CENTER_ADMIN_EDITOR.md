# Game Center admin editor plan

The editor should be generated from database stat definitions for the game's sport.

Sections:
- Game metadata/status/final score
- Period scoring
- Team stats
- Away roster athlete stats
- Home roster athlete stats
- Source and verification
- Recap
- Photos

The editor must support partial saves. An admin should be able to enter only a final score, only period scoring, or a full box score without filling irrelevant fields.
